# 「まちの続き」2066年記者会見シナリオ 統合記録

## 今回の位置づけ

「まちの続き」は、トップ画面の3つ目の入口、または `?prototype=1` から遊ぶ新しい一人用シナリオです。2056年に始まる市長の判断を記録し、その記録を参照して2066年の速報、記者会見、住民の声、手紙を組み立てます。このルートの判断履歴はこのブラウザー内のシミュレーションだけに存在し、`/api/*` を呼ばず、D1にも既存ゲーム状態にも書き込みません。

従来の2036年一人用4判断、共有7判断とD1、観戦画面、QR、v27の会見および結果カードは別ルートです。v27側の会見で使う「停止前・停止後」の比較は、実際のゲームでAIを停止した履歴ではありません。今回の新ルートでは、導入・稼働・停止・再開と案件ごとの判断を、実際に記録された履歴として扱います。

## 事実を保つための条件

- 決定、実施、住民影響、ニュースは、同じ `case_id` を参照するイベントとして記録します。市長の会見文は、選択中の事案と同じ案件の決定だけを市長の選択として話します。
- 事案記録後に選ばれた判断や行われた実施は、その時刻を確認し、先に起きた影響の原因として説明しません。
- 代理AIを未導入または停止中とした場合、AIのセリフや代理発言ログを作りません。停止前に実施済みの判断と、その後も続く影響は履歴に残します。未導入ケースには過去のAI判断を割り当てません。
- 会見の判断記録欄は、案件の市長選択、市の既存ルール、同じ案件でのAI判断、実施記録、住民影響を表示します。記録がない欄は「記録なし」とします。
- 影響の軽・中・重は、シミュレーション内の影響期間、影響を受けた住民数、未解消・支援の要否から決めます。これは創作ゲーム内の記録で、現実の予測や法的責任の判定ではありません。

## 進行と演出

1. 実際の街キャンバス上に「まちニュース速報」を短く表示し、事案のニュース記録を見せてから市長会見へ移ります。
2. 会見では市長、司会、記者、ひとつの市長代理AI表示を使います。市役所の人物肖像をAIの外見として流用せず、CSSの抽象表示とマイクで表します。
3. 市長の発言、記者の問い、約2秒の沈黙、AI稼働・停止・未導入に合わせた会話を再生します。停止・未導入ではAIのマイクを消灯し、AIは発話しません。
4. S1〜S5のうち、実際に影響が記録されたテーマを選び、そのテーマの住民の声と手紙を表示します。最後は短い沈黙のあと暗転し、「それ、誰が決めた？」を出して、レターID付きの手紙へ進みます。

S1〜S5は、同梱の素材にある5テーマと各テーマの手紙を引き継いでいます。個別のケース、条件、住民の声、手紙本文は `site/public/prototype-data.js` にあります。再現試験の60経路（5テーマ×影響3段階×AI状態4通り）は `site/tests/fixtures/prototype-cases.json` に固定し、ブラウザーで各経路を実行せずに決定エンジンを検査します。

## 互換性と配布物

- 起動判定は既存 `app.js` の初期化前に行います。`?prototype=1` ではプロトタイプUIだけを開始し、通常の `init()`、定期的な共有状態取得、共有用API呼び出しを開始しません。
- `prototype-data.js`、`prototype-engine.js`、`prototype-ui.js`、`prototype.css` は独立したファイルです。既存 `server.mjs` の配信実装は変更していません。
- 単体HTMLには追加スクリプトとCSSをインライン化します。ファイルを開いて通常ルートも新ルートも選べます。単体HTMLはソロ専用・オフライン動作です。共有プレイにはサーバーとD1が必要です。
- Worker成果物のビルド許可リストへ新しいUIアセットを加える必要があるため、`site/scripts/build.mjs` と単体HTML生成の `site/scripts/build-standalone.mjs` は変更対象です。Worker本体、D1スキーマ、マイグレーション、ホスティング設定、D1バインディングは変更しません。
- ビルドスクリプトは配布物の構成を変えるため、変更分類は `REVIEW_REQUIRED` です。この統合だけで本番公開できるという判定やR0判定は行いません。

## 画像・動画の扱い

会見、速報、住民の声、AI稼働・停止、暗転にはCSS/SVG相当の画面を標準表示として使います。`MEDIA` の動画参照フックは残し、素材を持たない場合も同じ字幕と画面で進行できます。外部動画配信や外部素材は必要ありません。会見補助AIの外見は人物肖像ではなく、抽象的な表示です。
