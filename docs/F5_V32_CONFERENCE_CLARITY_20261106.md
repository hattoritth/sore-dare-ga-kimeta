# F5 v32｜2066年・記者会見の操作と目的を明確化（2026-11-06）

## 来場者からの問題提起
v31一般公開後の記者会見スクリーンショットで、「この画面で何をすればよいか分からない」。従来は全面の暗い会見画面に長い説明、3種のAI状態、記者の質問、単なる「次へ」と「省略」が同列に混在し、現在地・操作・選択の意味が判別しにくかった。

## v32（PR #34固定v31を起点としたUI-only）
1. **会見の目的を明示**：見出し「2066年・もしもの記者会見」、ガイド文「これは仮想の場面。発言を読み、最後に結果と手紙を確認」。仮想の未来を実際のゲーム内出来事と混同させない。
2. **進行状況とCTA**：「会見 1 / N」で残りが分かる。最初は「最初の発言へ」、進行中は「次の発言へ」、最後は「街の結果と手紙へ」。スキップは「会見を飛ばして結果と手紙へ」。
3. **AI比較を任意操作へ**：当初は折りたたみ。「もしAIの使い方が違ったら？（任意で比較）」を開いた人だけ3つの状態を比較。比較の結果・6指標・本来の判断は変わらないことを明記。
4. **レイアウト**：PC/iPad横は街の情景（左）と読み進めるパネル（右）を分離。スマホは上に街、下に明るい文字パネルと主要CTA。色・行間・タップ領域を改善。固定QRが見出しに重ならないようスマホ会見中は街の左上へ配置。
5. **冗長な注釈を整理**：本文は想定影響のみ表示。これは仮想シーンだという注意を最初のガイドに集約（既存の未来シナリオデータ、イベント・結果の内容自体は変更しない）。
6. **再プレイ時の安全**：進行ラベルを消去し、任意比較メニューを閉じた状態へ戻す。

## 実装範囲・変更禁止
対象：`site/public/index.html`, `site/public/app.js`, `site/public/style.css`, QAテスト、生成単体HTML。このPRはUI-only。本番Worker、engine、SQL/schema/migration、hosting manifest、D1 binding、本番Site ID/URL、共有データ・採点ロジックに変更なし。main merge・Sites公開はこの改修では実施しない。
