# F5：練習なし・部長の相談・街の表示

## 変更

- `?mode=solo` と単体HTMLは、練習を挟まず最初の診療所の判断から始まります。`?mode=group` は参加受付へ進み、参加後は従来のロビーに入ります。導入は4場面のまま、台詞・入力速度・場面間の待ち時間を短くしました。スキップと `prefers-reduced-motion` は維持しています。
- ヒカリ、ソラ、ナギ、ミドリは市長政策会議に相談する架空の部長です。画面では氏名と役職を示し、議題ごとに市長へ短く相談します。相談の出どころはサイトごとに別ラベルで表示します。街づくりAIは市長が委任できる一つのシステムとして扱います。
- 診療所は1か所という条件、駅前の利用者数・通いやすさと、郊外で通院負担の重い人に届くことの違いを初回の説明に残しました。結果後のPNG/PDF、7枚の結末画像、6指標レーダーも既存機能を維持しています。
- 街の描画から、旧シミュレーション上の4体の `AGENTS` を歩行者として描く処理だけを削除しました。`F5City.AGENTS` と `CityModel` は内部互換性のため残し、一般の歩行者、車、列車、参加者アバター、建物は従来どおり描画します。会話欄の職員ポートレートは残しています。
- エンジンの得点、ソロ4判断、共有7判断、共有投票の23秒、AIの一回操作、API、D1、スキーマは変更していません。新しい依存関係や外部リソースも追加していません。

## 確認できる範囲

自動テストは練習ゲートがなくソロが本編を開始すること、共有が状態取得から参加受付・ロビーへ進むこと、7つの議題に自然な部長台詞があること、旧AI歩行者を描画せず一般の歩行者・交通・建物を残すことを確認します。全99テストが通過し、単体HTMLを既存ビルドで再生成、成果物検証も通過しました。

単体HTMLは一人用・オフライン用です。共有プレイにはサーバーまたはD1付きWorkerが必要です。ローカルのPlaywrightプレビューで390×844、1024×768、1920×1080を確認し、横はみ出しがないことと初回診療所の表示を確認しました。390×844では判断を選ぶ際に縦スクロールが必要です。iPad・iPhone・大型モニターの実機、本番Sites、実D1では確認していません。

## 既知の制約

ゲーム内の一部のエンジンIDや履歴語彙にある `agent` は互換性のため残っています。これは描画対象の職員や街づくりAIを4体に分ける意味ではありません。街のシミュレーション内容と経路・得点は今回変更していません。

## 選択肢の表示密度（追加）
「01/02」の番号・飾り矢印・重複する小文字説明は非表示。選択の主役は「自分で決める」（共有では「人の案に投票する」）と「AIに任せる」の2つ。人側の短い方針説明と表3指標の変化予測は残し、AI側は予測数値を見せずに1タップで決定する。決定後に実際の変化を表示する既存機能は維持。共有の予測は票数の影響を受ける旨をアクセシブルな補足情報として付与。

モード選択の装飾番号、説明文、矢印も省き、操作可能なボタン名だけを残す。第1の判断など進行状況に必要な表示は残す。
