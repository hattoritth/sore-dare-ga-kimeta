# 展示会場の封筒案内（v29）

新しい2056〜2066年ソロ体験の**最終レター画面**では、実際の結末 S1〜S5 に対応する封筒を**一通のみ画像表示**し、会場に置いた同色の封筒を持ち帰るように案内する。オンラインでの手紙表示とは別に、実物の封筒の内容・補充・印刷は会場運営側で用意する。

| レター | 体験したテーマ | 実物の封筒の色 | 画面上の基準色（SVG base） |
|---|---|---|---|
| S1 | 安全・安心 | 青 | `#428BC4` |
| S2 | 生活の豊かさ | 濃い緑 | `#297A59` |
| S3 | 公平性 | 紫 | `#9169B5` |
| S4 | 自由・自己決定 | 薄い緑 | `#B7DDA4` |
| S5 | つながり・生きがい | 黄色 | `#EBC454` |

実際に用意する封筒の色はこの表示色の目安に合わせ、色相と明度の区別がつくようにする。物理封筒にも **S1〜S5の番号** を掲示することを推奨。番号があれば、色覚・照明環境・印刷差による誤認を避けやすい。画面には1つの封筒イラスト、色名、テーマ名、レター番号を表示する。5色全体は結果画面に同時には表示しない。

**会場での動線：** 会見→最終レター画面→「会場にある封筒を1通お取りください。」→同色とレター番号の確認→封筒を持ち帰る。持ち帰りはユーザー自身の物理行動であり、アプリから取得済みかどうかは記録しない。

**技術境界：** HTML内のSVGイラストで表示するため、外部画像・ネットワーク接続・新しいWorker配信資産・D1変更は不要。既存2036年モードおよび共有モードは変更しない。実封筒の紙色は画面と完全一致を保証しないため、会場で照合する。
