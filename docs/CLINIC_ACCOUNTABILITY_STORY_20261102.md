# 診療所エピソード：判断理由と説明責任（2026-11-02）

## 採用した展示体験
- 相談者ヒカリの母は診療所まで片道1時間。街の予算では診療所を1つだけ整備できる。
- 駅前：利用者を多く見込め、仕事帰りにも便利。郊外：通院の負担が重い人が行きやすいが、利用者は比較的少ない。数量は架空シナリオの前提であり実統計ではない。
- **ソロ・人の判断**：建設場所（駅前／郊外）と優先する理由（利用者数／通院困難者）をそれぞれ選び、最終確認後に元の1票を投じる。人が決めても不利益を受ける住民がおり、本人の言葉で説明する。
- **ソロ・AIの提案**：駅前の提案を表示。予測利用者数、交通、人口構成という評価項目を閲覧できる。個人の事情がどれほど影響したかはこの提案の要約からは分からず、承認した人間に説明・検証責任が残る。
- **判断後**：Canvas街変化とともにソラ／ヒカリの問いを表示。評価の再調査、先行する通院支援、計画見直しを選ぶ。それぞれ時間・偏り・遅延の代償を明示。選択した対策は次の議題の台詞と結果履歴に反映。
- **共有**：23秒の多数決の負担を増やさず、最初の議題に簡潔な事情説明を追加。ソロの場所・理由をグループ全体の決定として誤記録しない。

## 不変条件
- ソロ4判断、共有7判断、6指標、影響予測、6種エンディング、投票ルール、D1 schema、Hosting manifestは変更しない。
- 診療所の詳細選択とその後の対策は**物語上の選択**。新たな得点変化も投票数増加も起こさない。
- 理由／対応はソロのブラウザ内の今回のプレイに限って保存し、再読み込みでは消える。実D1へ送信・保存しない。
- 裏3指標の値は引き続きゲーム終了まで秘匿。
