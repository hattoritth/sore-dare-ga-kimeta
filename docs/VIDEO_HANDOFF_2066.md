# 会見映像の引き渡し・差し替え仕様

現在はCSS背景と既存のSVG人物を使い、字幕・マイク点灯・分岐・進行を動かしています。完成映像は別工程の対象です。完成した60本の動画は不要です。

## 11個の素材ID

| ID | 内容 | 推奨素材尺 | 字幕・切替の基準 |
|---|---|---|---|
| S1_FIELD | 避難案内を確かめる水辺地区 | 4〜6秒 | 宮本さんの一言。自動サービス未実施なら確認待ちの台詞 |
| S2_FIELD | 買い物環境の変わった旧市街 | 4〜6秒 | 山田さんの一言。配送未実施なら支援を待つ台詞 |
| S3_FIELD | 入園の結果を待つ家庭 | 4〜6秒 | 森さんの一言 |
| S4_FIELD | 川沿いの道・案内 | 4〜6秒 | 河野さんの一言。実際の運用に合わせ字幕を変更 |
| S5_FIELD | 家族連絡・訪問調整 | 4〜6秒 | 娘の一言。連絡代行未実施なら支援を待つ台詞 |
| CONF_OPEN | 会見室全景・記者の質問 | 5〜8秒、ループ可 | 最初の質問、追加質問、最後の問いで再利用 |
| CONF_MAYOR | 市長の回答・視線 | 6〜8秒、ループ可 | 実際の手動選択を動的表示。複数カットで再利用 |
| CONF_SILENCE | 市長の沈黙 | 2〜4秒、ループ可 | 追及約4秒、その後「……」約2秒 |
| CONF_AI_ON | AIのマイク点灯・自然な代理説明 | 6〜10秒、ループ可 | 導入4秒、経緯9秒、必要なら追加5秒・お詫び6秒 |
| CONF_AI_OFF | マイク消灯・判断記録に視線を向ける | 6〜10秒、ループ可 | 停止／未導入の質問と事実記録。AIの発言は入れない |
| CONF_END | 会見後の暗転 | 3秒 | 「それ、誰が決めた？」の字幕後にレター表示 |

重大度によって映像差分が必要な場合だけ別ファイルを追加し、同じIDへの設定を切り替えます。現在の実装は1IDにつき1ファイルです。L/M/Hの違いは字幕と実際の記録で表現しています。

## 素材の仕様

- 推奨：MP4（H.264、yuv420p）、1920×1080、16:9、24または30fps。WebMもローカルサーバーで配信できます。
- 無字幕・無音を推奨。実際の数値、選択した対応、AIの判断内容、お詫び文を映像に焼き込まないでください。
- 映像を引き伸ばすのではなく、字幕表示中はループします。端末によりトリミングされるため、顔・マイク・重要な物体は中央寄りの安全領域に置いてください。
- 長い台詞は「一時停止」で読めます。「次へ」とスキップは映像の終了待ちをせず動きます。
- 現在は字幕の音声読み上げ・口形同期は実装していません。音がなくても成立する素材にしてください。

## 差し替える場所

対応表は **`site/public/prototype-data.js` の `MEDIA` だけ**で管理します。ファイルを `site/public/media/` に置き、該当IDを設定します。

```javascript
// MEDIAを作成している箇所の直後で、該当するIDを設定する例
MEDIA.CONF_OPEN = {
  src: '/media/conf-open.mp4',
  poster: '/media/conf-open.jpg',
  loop: true
};
```

`poster` は任意です。`src: null` のままなら現在の背景を使います。動画が読み込めない場合や自動再生できない場合も、CSS背景と字幕へフォールバックします。再生には `muted` と `playsInline` を指定しています。実際のMP4を納品後、iPad/Safariでのコーデック・自動再生・負荷確認を行ってください。

字幕・カット順・秒数は **`prototype-engine.js` の `conference()`** が返す `{clip, speaker, text, duration}` を参照します。`duration` はカット開始を0とした字幕の表示時間（秒）です。会見開始時に実際のプレイ履歴から生成し、`prototype-ui.js` がその順番で動画と字幕を切り替えます。映像のメタデータ読み込みや音声の長さを根拠に分岐しません。

会見時に代理判断が有効なら、AIが「市長に代わって、判断の経緯をご説明します。」と表示されます。停止中・未導入ならAIのマイクは消灯し、AI話者の字幕も生成しません。Hのお詫びも、AIの既定文案／市の表明として扱い、市長本人が文案を作成・承認したという字幕にはしません。

## 納品後の確認

1. ローカル起動し、各素材の読み込みとスマートフォンの切り抜き位置を確認。
2. ONとOFFそれぞれで、字幕とマイクの状態を確認。
3. 読み込めないファイルで背景と字幕が残ることを確認。
4. 一時停止・次へ・スキップ・リプレイを確認。

今回のWorkerビルドはソースに同梱するテキスト資産だけを埋め込みます。追加動画を本番Workerへ配信する場合は、ASSETS等でバイナリを配る設定を別途追加・確認してください。今回のローカルサーバーは `public/media/` のファイルを配信できます。動画のHTTP Range対応と本番配信の設計は今回の対象外です。
