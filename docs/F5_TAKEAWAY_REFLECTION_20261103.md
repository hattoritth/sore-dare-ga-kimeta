# F5「判断の記録を持ち帰る」

## 方針

結末画面で記者会見を終えるか省略した後、今回の判断と街の結果を日本語のテキストとして保存・コピーできるようにしました。生成処理は `site/public/reflection-report.js` の純粋関数で、ブラウザー内の結果状態から決定的に組み立てます。再生中は `phase === 'reveal'` でないためレポートを生成せず、6指標すべてと結末がそろわない場合も表示しません。

## 記録する内容

- 結末、状態に含まれる実際の事象または残っている課題、6指標の名称と値。
- 各議題で人の方針が選ばれたか、AIに任せる方針が選ばれたか、同数票・無投票で保留したか。
- 共有プレイでは議題ごとの人票・AI票の集計。特定の参加者が賛成・承認したとは記しません。名前、Cookie、トークン、秘密鍵は含めません。
- ソロでは、提供された場合に限り診療所の場所・理由・対応と人間側の検討方針を記録します。いずれもブラウザーだけにある物語上の選択で、現実の運営、実際の行動、指標・得点への効果を意味しません。
- 最後に「それ、誰が決めた？」を振り返る問いと、展示シナリオであり個人の心理を推測しない旨。

保存・コピーは現在の画面内で生成したテキストを使います。レポートをネットワーク送信したり、ブラウザーの保存領域に記録したりしません。クリップボードAPIが使えない場合は、手動コピー用の選択可能な欄を表示します。

## 検証

`site/tests/reflection-report.test.cjs` で、進行中の非表示、6指標の完全性、ソロ4議題、共有7議題、同数票・無投票、診療所と人間側方針の物語上の境界、実際の状態にない災害を追加しないこと、個人情報を出さないこと、決定性を確認します。

親側Macの通常実行では npm test が85/85件すべて成功。Codexの隔離環境で既存HTTPテスト2件が失敗した理由は待受け制限（listen EPERM）でした。Worker成果物の検査・単体HTML生成・差分検査も成功しています。Playwright/ChromiumではローカルHTTP配信でソロ4判断を完走し、会見省略後の6指標、保存・コピーUI、実際のテキストダウンロード、クリップボードコピー、390/1024/1920pxで横はみ出しなしを確認しました。実機Safari、共有の全7判断のブラウザー実操作、新版のSites本番公開は未検証・未実施です。D1、Worker API、スコア計算、既存ホスト済みマイグレーションは対象外です。
