# ソロの詳細選択と街への影響

4回の判断のうち、人が決めるときの詳細選択も街の数値に反映する。指標はエンジン内で同じ6項目を使い、上限・警告・終了の既存条件を変えない。プレイ中に見えるのは「にぎわい・便利さ・住み心地」の3項目だけ。残る3項目は結末まで公開しない。

## 選択と効果

以下は各項目への追加分。第1回は通常の診療所案、第2〜4回は通常の議題案に加算する。100を超える値と0未満は既存どおり丸める。

| 場面 | 選択 | にぎわい | 便利さ | 住み心地 | 信頼 | 公平さ | 備え |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 診療所の場所 | 駅前 | +2 | +4 | 0 | 0 | −3 | 0 |
| 診療所の場所 | 郊外 | −1 | +1 | +2 | 0 | +4 | 0 |
| 優先理由 | 総利用者数 | +2 | +1 | 0 | 0 | 0 | 0 |
| 優先理由 | 通院の届きやすさ | 0 | +1 | 0 | +1 | +2 | 0 |
| 人の方針 | 現地の声 | −2 | +1 | +1 | +3 | 0 | 0 |
| 人の方針 | 地区間の調整 | −1 | −1 | 0 | +1 | +3 | +2 |
| 診療所の後対応 | 評価を調べ直す | 0 | −1 | 0 | +4 | +2 | 0 |
| 診療所の後対応 | 通院を先に支援 | −1 | +3 | +1 | 0 | +1 | 0 |
| 診療所の後対応 | 計画を見直す | −1 | −2 | 0 | +1 | +3 | 0 |

第1回の場所・理由は、人が診療所案を選んだ場合のみ有効。後対応は初回の街の変化が確定した後に選び、同じ履歴行と最終指標へ一度だけ加える。AIへの委任は追加確認なしで実施し、詳細選択を挟まない。第2〜4回の方針選択も人の案を選んだ場合だけ有効。

## バランスと限界

どの選択も全指標を上げない。駅前と郊外は便利さ・住み心地・公平さの配分が異なり、総利用者数と通院の届きやすさも成長側と公平さ側で差が出る。現地の声は信頼と住み心地を支え、地区間の調整は公平さと備えを支える一方、どちらも成長・便利さに小さな費用がある。後対応も、調査・支援・計画変更で効果先が異なる。

追加分は固定値で、選択による指標変化を短いプレイでも確かめやすくした。人口構成、選択の前後関係、先のラウンドへ持ち越す施策効果はモデル化していない。実際の行政施策や医療提供を予測する値ではない。共有プレイではこれらの詳細選択を使わず、従来の投票集計とラウンド処理を維持する。
