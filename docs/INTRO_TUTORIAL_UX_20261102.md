# 入口UX改善：入力中アニメーション／1ターン練習

2026-11-02

## 目的
新規プレイヤーが、イントロの自動進行中にフリーズしたと誤認しないこと。また、遊ぶモード選択後に説明なしで判断ボタンが現れないこと。

## 実装
- イントロの文章表示中・表示後の待ち時間に3点アニメーションと「入力中…／次のメッセージを入力中…」を表示。最終場面では「街への案内を準備中…」。次へ・スキップと4場面自動進行は維持。
- 街の初期Canvas描画を待つ間、「街を描いています…」アニメーション付きの軽いプレースホルダーを表示。最初の正常なカラー描画後に消す。
- ソロ・共有ともに、本編前にヒカリとの練習ターン。公園のベンチをどう配置するか、利用者に聞くかAIに任せるかを1回選択 → 反応 → 本編（共有は参加フォーム）へ。スキップ可能。
- 練習には実投票API/ゲームエンジンを使わず、指標、判断回数、D1、既存プレイ状態を変更しない。ソロ4判断／共有7判断は維持。
- 共有参加者がページを再読込した場合、Cookieから参加者と判定されれば練習を飛ばして現在のプレイへ復帰。
- prefers-reduced-motion 設定時は装飾的な動きを抑える。
