# 診療所エピソードの短い表示文

診療所の結果画面では、1画面に1つの住民の声と次の問いを置く。場所は実際の選択結果から見出しに表示し、残る課題を住民の一文で示す。「どうする？」の下には3つの対応を並べ、行動と主な代償を別行で読めるようにする。

| 対応 | 表示する代償 | 保つ意味 |
| --- | --- | --- |
| 根拠を確かめる | 調査には時間がかかる | 判断の根拠を調べ直す |
| 通院を支援する | 場所の偏りは残る | 先に移動負担を軽くする |
| 計画を見直す | 便利さが下がる | 診療所の場所を再検討する |

場所選択では駅前の利用者の多さ・便利さと、郊外で通院負担を減らせることを短く示す。人の判断で選ぶ場所と優先理由、AIが駅前を勧める根拠項目と個別事情への説明限界は残す。

表示文の変更は選択値 `review` / `support` / `revise`、エンジンのスコア、共有投票に影響させない。街の公開3指標の実際の増減表示も維持する。

街の変化カードが表示されている間は、地図上の長い結果字幕を非表示にして重複を避ける。判断の詳細はゲームの履歴に保持する。
