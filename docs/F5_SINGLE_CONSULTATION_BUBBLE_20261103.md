# 市長政策会議の相談UI簡素化（2026-11-03）

## 起点
実機iPhoneの公開v15スクリーンショットでは、診療所の議題に「相談元タグ」「大見出し」「説明文」「部長の発言」「市長としてどう決めますか？」が重複し、1つの相談を5回読ませていた。

## 変更内容
- 部長の氏名・役職を残し、吹き出しの本文を**市長へ話しかける自然な質問1つ**に統合する。
- 診療所のように対立軸が必要な案件だけ、吹き出しの下に**1行の判断材料**を残す。その他は発言文だけで判断できる設計。現実の住民、企業の出所は発言の中で明示し、部長本人の個人的経験と誤認させない。
- 相談元の別タグ、議題見出し、選択前の冗長な「市長としてどう決めますか？」、操作を誘う装飾リンクを削除。
- 既存の選択肢、自分で決める側の表3指標予測、AI側の予測非表示と1タップ、職員の4人、人の細かな判断、共有7議題、街の描画、6指標、結果カードは保持する。
