# 選択前の指標変化プレビュー（2026-11-02）

## 目的

カイロソフト風に、実際の選択を押す前に街の指標がどちらへ動くか把握できるようにする。
「繁栄 −」「便利さ ＋＋」などを選択ボタンに小さく表示する。
**`±0` は表示しない**。変化のある指標だけを描画する。

## 仕様

- 表の3指標（繁栄・便利さ・街の魅力）だけを表示。裏の3指標（信頼・公正・持続性）は結果が出るまで非公開。
- 選択肢ごとの変化はエンジンの最新ルール（エピソード固有効果、同じ方法への依存コスト、回復効果、0〜100上限）を複製状態に対して試算する。元のゲーム状態や実D1は変更しない。
- 符号の目安：差分0は非表示。絶対値1〜4は1符号、5〜11は2符号、12以上は3符号。`+`は上昇、`−`は下降。
- プレイヤー向けの表示は符号だけ。正確な値と裏指標への影響は見せない。
- 共有モードは「全員が同じ案を選んだ場合」の比較。実際は多数決の得票割合で変化するため、その旨を記す。
- 上下の色だけに頼らず `+`/`−`、ラベル、アクセシビリティ読み上げを併用。
- `±0` を非表示にしても、裏の値まで変化なしと誤解されないよう注記を残す。

## 検証

- Mac Node.js `npm test`：60/60 PASS。実際のエンジンで予測と判断結果の表3指標の変動を比較し、試算が元状態を変更しないことを確認。
- Mac Chrome：390×844 iPhone相当のソロ、1024×768 iPad横相当の共有、1920×1080 PCのソロで24/24 PASS。共有テストでは「便利さ ±0」「魅力 ±0」のデータを注入し、該当チップが消えることを確認。横スクロールなし、44px以上の選択領域、JSエラーなし。
