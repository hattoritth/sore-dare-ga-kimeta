# P1 街の変化演出と結末の段階表示

## 変更内容

- 決定結果がサーバーまたはソロエンジンで確定し、投票結果が実施されたときだけ、対象施設の敷地にCanvasの二重リングと短い地点ラベルを表示する。座標は街の2.5D投影から毎フレーム求めるため、画面サイズ・ズーム・カメラ位置に追従する。
- 共有7議題とソロ4議題は既存 `SOLO_STORY` / `EPISODES` の順に対応。混合票、無投票、延期ではマーカーを出さず、既存の建物配置や得点計算には手を加えない。イベント識別子で同じポーリング結果を再生しない。街の再開始時は消去する。
- 結果表示を「変わった街の絵 → 結末 → 理由と警告 → 6指標 → 保存」に分ける。絵は `EndingCard.sceneSvg` の安全な単独イラストを使い、最初の段階では見出し・指標・会見の内容を表示しない。各段階はボタンで進み、共有モードにも一括表示を用意した。結末の絵は安定時だけ成功の街を使い、警告・保留は中立の絵を使う。
- 指標と結果カードはそれぞれ所定の段階で初めて描画する。PNG、印刷/PDF、振り返り保存は最終段階で従来のデータを利用する。

## 動きとアクセシビリティ

- 地点マーカーは通常850ms、`prefers-reduced-motion` では静止表示。リングは変更地点の地面に描き、画面全体を覆わない。
- 段階送りは自動タイマーを使わず、押すと即時に進む。タップ対象は既存ボタン基準の44px以上。

## 制限と受入確認

- 地点は既存の議題順と実際の `built` 値から特定する。施設の応答選択による指標変化は追加の建設演出にしない。
- ブラウザ描画・実機の390×844、1024×768、1920×1080での視覚確認は、この作業記録だけでは完了扱いにしない。Canvasの表示はデバイス・ズームによる目視確認が必要。
- `site/tests/p1-city-motion-ending-flow.test.cjs` は段階ゲート、保留時の演出抑止、イベント重複防止、reduced-motionの静止状態をソース回帰チェックする。

- マーカーは2.5Dの地点を投影した後、画面上のCSSピクセルでリング・ラベルを描画する。スマートフォンで地図が縮小されても文字とリングの大きさは保たれる。表示名は実際の建設種類 `built` に由来し、AI案を人の案の施設名で誤表示しない。
- 最終保存段階から記者会見を任意で開始・再生できる。会見は段階表示・PNG/PDF保存の前提条件にしない。街の初期イラストは読み上げ時に結末名を先取りしない。

## 結果画面と保存カードの読みやすさ

- 結果欄の幅に合わせ、公開3指標と最後に明らかになる3指標を縦に並べる。各行は指標名・バー・数値の3領域を確保し、意味や警告はその下に折り返す。画面全体の幅を基準に2列へ切り替えない。
- 5段階目の画面内プレビューはレスポンシブなHTMLで描画し、見出し・説明・街の絵・6指標を通常の文字サイズで読めるようにする。第4段階より前は指標名と数値を描画しない。
- PNGと印刷/PDFには、別に生成した1600×1100のSVGを使う。SVGでは見出しと説明を複数行にし、街の絵・レーダー図・6指標を独立した領域に配置する。印刷時はA4一枚に収める。
- `site/tests/decision-ux.test.cjs` はプレビューのHTML出力、SVG寸法と全指標、文字のエスケープ、画面プレビューと印刷/PDF出力の分離を検査する。実ブラウザの幅・倍率ごとの表示は自動テストとは別に確認し、検証範囲を完了報告に記載する。

## 結末画面のレイアウト修正（PR #14追加、2026-11-03）

- 修正前は結果パネルの幅とは無関係に「画面全体が広いと2列」の判定があり、狭いサイドパネルで指標名・バー・数値が衝突していた。幅依存の2列をやめ、結果パネルの実幅内で3指標ずつ縦並びにした。
- 結果カードの画面プレビューは固定1600×1100の縮小表示を廃止。見出し・説明・結末の絵・6指標を読みやすいHTMLレイアウトで表示する。保存は従来どおりPNG / 印刷PDF。
- 保存専用SVGは見出し・説明を折り返し、街の絵・レーダー・6指標を重ならない領域に配置。印刷時は不要なゲーム画面のDOMを非表示にしてA4縦1ページのみ出力する。プレビューと印刷用データは同じ最終状態から生成する。
- Mac通常環境で119/119件の既存回帰テストと追加テストが成功。390、500（2倍ピクセル比）、768、1002、1024、1366、1920px幅で、実DOMの横スクロール・6指標の重なりがないことを確認。長い結末の保存SVGで21文字要素のクリッピング・衝突0件をブラウザーで確認し、PDFのページ数を2→1へ修正・再確認。更新後PNGもブラウザで227,299 bytesの実ファイル生成を確認。
- 実機iPhone / iPad Safariと本番Sitesの受入検証は別途必要。一般公開済みのv16・D1・Worker・エンジン・スコア・共有投票は変更しない。
