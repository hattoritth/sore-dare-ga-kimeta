# それ、誰が決めた？

AIに任せるか、人が判断するか。街の見える発展と見えない社会の変化を体験するAIゼミ展示用のゲーム。

**開発のSource of Truth：このPrivate GitHubリポジトリ。**

## 体験の基本
- 表示タイトル：「それ、誰が決めた？」
- 世界観：2036年。AIに任せるうちに、誰が決めたのかわからなくなる未来
- 「まちの続き。」は作中の街の名前・副題として使用可能
- 入口は導入ストーリー→「ひとりで遊ぶ／みんなで遊ぶ」
- ヒカリ・ソラ・ナギ・ミドリとのRPG会話→「人が判断／AIに任せる」→街の変化
- 見える3指標：繁栄・便利さ・街の魅力
- 隠し3指標：信頼・公正・持続性。結末以外ではUI・公開APIから秘匿
- iPadはスタンド横置き1024×768を中心に、iPhone縦390×844・モニター1920×1080にも対応
